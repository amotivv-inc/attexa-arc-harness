# Support

Attexa Arc Harness is currently a pre-alpha open-source project.

## Community support

Use GitHub issues for:

- reproducible bugs;
- documentation problems;
- bounded feature proposals;
- compatibility questions;
- public architecture discussion.

Use the RFC process for changes to kernel semantics, public contracts, compatibility, authority, evidence, recovery, or governance.

Do not use public issues for security vulnerabilities. Follow [SECURITY.md](SECURITY.md).

## Current support level

The project currently provides no production service-level agreement, guaranteed response time, long-term compatibility promise, or support commitment for experimental commits.

Maintainers may prioritize work according to architectural importance, security, reproducibility, community impact, and available capacity.

## Managed Attexa Arc

The open-source project contains the harness architecture, reference implementation, contracts, adapters, and conformance tools.

Managed Attexa Arc is the supported workplace, infrastructure, integration, governance, and trust-service product built around it. Commercial support and managed-service terms are separate from this repository and the Apache License.
