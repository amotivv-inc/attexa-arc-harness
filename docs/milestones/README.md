# Milestones

Milestones are durable records of meaningful evidence gates reached by Attexa Arc Harness.

They are not a development diary, release calendar, or replacement for [STATUS.md](../../STATUS.md). The current status page may advance beyond a milestone record; the milestone preserves what was demonstrated, how it was assessed, and what remained outside scope at that point.

## Planned gates

- **0002 — First real downstream harness:** a real OpenCode `HarnessAdapter` and two simultaneous sandboxed child loops.
- **0003 — Public technical preview:** sanitized source, tests, evidence, and setup reproducible from a fresh public checkout.

## Record rules

Each milestone must state:

- scope and explicit exclusions;
- availability and evidence levels;
- development and reproduction method;
- source availability;
- known defects and pending amendments;
- provenance references;
- whether an outside party can reproduce it.

Later corrections or evidence upgrades should be appended as amendments.
